# Selling subdivided claims as plots
## Create a properties company
You have to (partially) own a company of the type "**properties**" to sell plots. Create one if you don't own one. For this, make sure you are at least level 50 in the server. View your current level with /levels. To create a company, use `/create company`, and click the link. **Select "Properties" as company type.** Read through the contract and attach a fictional signature on the page.

## Claim a plot
Plots that are for sale must always be a *subdivided* claim. So to create a claim that is ready to be sold, make a normal claim (that can hold multiple subdivided claims), hold a golden shovel and type `/subdivideclaim`. Then click from corner to corner to create a subdivided claim.

## Create a sign to sell a plot
Players can buy a plot by clicking a sign. Place a sign within the subdivided claim, with this on the sign:
   - line 1: literally `[plot]`
   - line 2: the price of the plot
   - line 3: the company name (of type "properties")
   - line 4: leave empty or type "one at most"

Line 4 has two options: leaving empty means that the player can buy an unlimited amount of plots within the parent claim. Typing "one at most" will only allow a player to buy one plot within the parent claim. Useful if you don't want the player to buy multiple or all plots.

That's it! Plots are listed on the website as well: https://survival.rocks/plots
